# Flutter Themez

![pub package](https://img.shields.io/pub/v/flutter_themez)

## Features

- Light
- Dark

## Fixes

The following widgets have various issues in Flutter's default theme.

- AppBar
- BottomAppBar
- Checkbox
- Chip
- ElevatedButton
- Icon
- NavigationRail
- Radio
- SnackBar
- TabBar
- Text

## Additional information

The [generated documentation](https://pub.dev/documentation/flutter_themez/latest) has a great overview of all that is available.
